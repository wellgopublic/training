# 研修の流れ — 制作ルール

WE'LLGO 研修サイトのページを追加・修正するときのルール。

## ページ構成

```
研修タイムテーブル.html      トップ（週ごとの一覧・ここから各ページへ飛ぶ）
manual/                    元データの PDF
Picture/                   PDF から書き出した PNG（カテゴリごとのフォルダ）
  10大栄養素/
  筋肉/
  ストレッチ/
pages/座学/                 座学ページ
pages/小テスト/              小テストページ
assets/zoom.js             画像クリックで拡大・ズームするビューア（全ページ共通）
```

## 画像のルール

### 1. 画像のまわりに説明文を書かない

**画像の下（キャプション）にも、上（見出し）にも、説明文は付けない。画像だけを並べる。**

manual の PDF ページをそのまま貼っているので、見出しも説明もすでに画像の中に印刷されている。まわりにもう一度テキストを置くと同じ内容が二重になるだけ。

```html
<!-- ○ 正しい：画像だけ -->
<figure class="hero"><img src="../../Picture/10大栄養素/タンパク質1.png" alt="タンパク質1 - 基本"></figure>
<figure class="hero"><img src="../../Picture/10大栄養素/タンパク質2.png" alt="タンパク質2 - ホエイプロテイン"></figure>

<!-- × 下にキャプションを入れない -->
<figure class="hero"><img src="..." alt="..."><figcaption>① 基本・役割・食品</figcaption></figure>

<!-- × 上に見出しブロックを入れない -->
<div class="sec">
  <div class="lab">Form</div>
  <h2>やり方 ／ ท่าปฏิบัติ</h2>
  <p>説明・注意ポイント・メインに使う筋肉</p>
</div>
```

`.hero figcaption` や `.sec` の CSS も書かない。`alt` 属性は画像が表示できないときのために残す。

**「出典」カードも付けない。** どの manual から作ったかはページに書かない。

残すのはページ自体の見出しとナビゲーションだけ ——`.back` の戻るリンク・`.kicker`・`h1`・`.meta`・`.nav` のページ切りかえボタン。それ以外は画像だけを並べる。

**例外:** `pages/座学/01〜13`（筋肉ページ）の `<figure class="fig">` は別。あちらの画像は manual の PDF ページではなく 3D 解剖ソフトの画面で、文字が入っていない。だから次の2つは付けてよい（消さない）。

- 番号＋筋肉の名前＋ふりがな。ページの本文そのもの。
- `.sidebox`：画像の右に置く説明ボックス。中身は manual に書いてある働き・オススメの人・種目をそのまま写す。

**説明ボックスがある図**（`<figure class="fig split">`）は、番号と筋肉の名前もボックスの中に入れる。画像の下に `<figcaption>` は置かない。

```html
<figure class="fig split">
 <div class="body">
  <div class="imgwrap"><img src="../../Picture/筋肉/大胸筋上部.png" alt="大胸筋上部"></div>
  <aside class="sidebox">
   <div class="hd">
    <span class="num">01</span>
    <div class="ttl"><ruby>大胸筋上部<rt>だいきょうきんじょうぶ</rt></ruby></div>
   </div>
   <p>…働き…</p>
   <div class="ex"><b>種目</b>：…</div>
  </aside>
 </div>
</figure>
```

**説明ボックスが無い図**（`<figure class="fig">`）は、これまでどおり画像の下の `<figcaption>` に番号と名前を書く。

### 2. 画像をクリックすると拡大できるようにする

画像がある座学ページには、`</body>` の直前にこの1行を入れる。

```html
<script src="../../assets/zoom.js" defer></script>
```

`assets/zoom.js` が `.imgwrap img` と `.hero img` を全部自動でひろって、クリックで全画面ビューアを開く。ホイール／ピンチ／＋−ボタンで拡大、ドラッグで移動、ダブルクリックで拡大↔もどす、`Esc`・背景クリック・×で閉じる。CSS もこのファイルの中に入っているので、ページ側に足すものは無い。

画像の `alt` はビューア上部の見出しになるので、必ず中身のわかる文字を入れる。

### 3. 画像は必ずカテゴリのフォルダに入れる

`Picture/` 直下には置かない。パスは `../../Picture/<カテゴリ>/<ファイル名>.png`。

### 4. 内容は必ず manual の PDF から取る

座学も小テストも、対応する PDF のページ・画像から作る。内容を創作しない。詳しくは「小テストのルール」を見る。

### 5. h1 の下にサブタイトルを置かない

以前は全ページの `h1` の下に `<div class="meta">No.3 ／ 起始・停止・働きを学ぶ</div>` のような行があったが、全部消した。同じものを作り直さない。

`h1` の上下に残すのはこれだけ ——`.back` の戻るリンク・`.kicker`・`h1`・（あれば）`.nav`。番号はトップページのチップに出るので、ページ側には書かない。

`h1` の下の余白は `h1{margin-bottom:30px}` で取っている。

### 6. 空のカードを置かない

**中身が決まっていないカードは作らない。** 「ここに◯◯を記載します」のような仮の文だけのカードは置かない。

以前は筋肉ページに `ポイント・関連知識` という空のカードが入っていたが、manual に対応する内容が無く、ずっと仮の文のままだったので全ページから削除した。同じものを作り直さない。

筋肉ページに置くカードはこれだけ：

- `.keys`（`起始` ＋ `停止` の2枚組）
- `働き（Action）`
- manual にその筋肉だけの補足が書いてあるときは、そのためのカードを足してよい（例：`08-僧帽筋` の `種目のポイント`）

`種目` は画像の右の `.sidebox` に書く。カードにはしない。

## 小テストのルール

### 1. 出典は manual だけ

**小テストの問題は、対応する manual の PDF に書いてあることだけで作る。**

- ネットの記事・参考書・一般常識など、**ほかの情報源は一切使わない**
- 自分で内容を考えて足さない
- manual に載っていないことは出題しない

manual に書いていないことを出題すると、研修生は「習っていないこと」を聞かれることになる。答え合わせのときも、必ず manual のどのページに書いてあるかを指せる問題にする。

### 2. 語彙は N5〜N3 まで

**日本語能力試験の N5〜N3 レベルの言葉だけを使う。難しい言葉は使わない。**

研修生はタイ人で、日本語を勉強しながら研修を受けている。問題文が読めなければ、内容を分かっていても答えられない。

- 問題文・選択肢は、やさしい日本語で短く書く
- N2・N1 の単語や硬い言い回しは、やさしい言葉に言い換える
  - × 摂取する → ○ 食べる／とる
  - × 促進される → ○ よくなる／すすむ
  - × 適切な → ○ ちょうどいい
  - × 〜が挙げられる → ○ 〜があります
- 一文を長くしない。一文に一つのことだけ書く

**専門用語は例外。** 筋肉の名前（大殿筋 など）、栄養素の名前（食物繊維 など）、`ダイナミックストレッチ` のようなカタカナ語は、研修で覚える言葉そのものなので、そのまま出す。ただし**そのまわりの文は N5〜N3 で書く**。難しい漢字にはふりがな（`<ruby>大殿筋<rt>だいでんきん</rt></ruby>`）を付ける。

### 3. 分量

1ページ 5問程度。すべて日本語。

## PDF を PNG にする方法

この PC には Python も poppler も入っていないので、Windows 標準の PDF API（`Windows.Data.Pdf`）を PowerShell から呼んで書き出す。幅 1400px で書き出すと既存の画像と同じくらいの解像度になる。

## トップページからのリンク

`研修タイムテーブル.html` の各項目は、ホバーで「座学 / 小テスト」を選ぶポップオーバー形式：

```html
<span class="m">項目名<span class="m-pop">
  <a class="pop-item" href="pages/座学/....html" onclick="event.stopPropagation()"><span>1</span>座学</a>
  <a class="pop-item" href="pages/小テスト/....html" onclick="event.stopPropagation()"><span>2</span>小テスト</a>
</span></span>
```

小テストがない項目（ストレッチなど）は、ポップオーバーを使わず座学ページへ直接リンクする：

```html
<a class="m" href="pages/座学/....html" onclick="event.stopPropagation()">項目名</a>
```

`onclick="event.stopPropagation()"` は必須。付けないとクリックしたときに WEEK のパネルが閉じてしまう。

## デザイン

全ページ共通。新しいページは既存ページの `<style>` をそのままコピーして使う。

- メインカラー `#004aad`、背景 白
- フォント: Zen Kaku Gothic New（見出し）／ Noto Sans JP（本文）／ Outfit（英数字ラベル）
- 本文幅 `max-width:760px`
- 文字コードは UTF-8（BOM なし）で保存する
